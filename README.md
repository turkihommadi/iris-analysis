 Iris Dataset Analysis

 Project Description

This project analyzes the Iris dataset using Python and Pandas. The project was created using uv and Jupyter Notebook.

 Setup Instructions

1. Create and activate the Python virtual environment.
2. Install the project dependencies using uv.
3. Start Jupyter Notebook.
4. Open `iris_analysis.ipynb`.
5. Run the notebook cells from start to finish.

 Dependencies

- Python 3.12
- Pandas
- Jupyter Notebook
- uv

 Dataset

The Iris dataset contains 150 rows and 5 columns:

- sepal_length
- sepal_width
- petal_length
- petal_width
- species

 Findings

- The dataset contains 150 rows and 5 columns.
- There are 3 unique Iris species.
- Each species contains 50 flowers.
- There are no missing values.
- The dataset contains 1 duplicate row.
- The average sepal length is approximately 5.84.
- The maximum petal length is 6.9.
- The minimum sepal width is 2.0.
- Virginica has the highest average petal length.
- There are 61 flowers with a sepal length greater than 6.

 Output Files

The analysis produces two CSV files:

- `output/species_summary.csv`
- `output/filtered_iris.csv`
